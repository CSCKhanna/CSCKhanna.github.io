# URI Academic Affairs AI Task Force Report 2026

Interactive browser presentation based on the final URI Academic Affairs AI Task Force Report 2026 Update.

## Local Use

Open `index.html` directly in a web browser. The deck is self-contained and embeds the report cover, URI wordmark, and contextual factors figure as data URIs.

## Navigation

- Left/right arrows move through the main presentation sections.
- Up/down arrows move through vertical drill-down slides.
- Escape opens or closes the slide overview.
- Alt+H opens the help dialog.
